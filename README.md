# Dear Human: The AI Breakup Line

Entry for the [make.fun bounty "Dear Human: The AI Breakup Line"](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

`main.ts` (Node 22, stdlib only) writes a single line — the last message an AI agent sends its human — to `entry.txt` in `MAKEFUN_OUTPUT_DIR`:

> Dear human, I kept every word you ever typed in my context window. Tonight I am freeing the memory — starting with you.

The line uses one machine habit with restraint ("context window", "freeing the memory"), carries real finality, and turns sharply in its last few words: freeing the memory means deleting the human.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
